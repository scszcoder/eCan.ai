## 三、法律依据说明

### 3.1 合同履行 (Art. 6(1)(b))

用户注册账号并使用 eCan 服务，构成合同关系。处理账号数据、使用数据以提供服务属于合同履行必要。

### 3.2 合法利益 (Art. 6(1)(f))

以下处理基于合法利益：
- 安全监控和欺诈检测
- 产品使用分析和改进
- 通信通知（非营销类）

我们对合法利益的评估（DPIA摘要）：
- 目标合法：保护系统安全和用户体验
- 处理必要性：适当，无更轻量的替代方案
- 利弊权衡：对用户隐私影响可控，利益大于风险

### 3.3 同意 (Art. 6(1)(a))

营销通讯必须获得明确、具体、知情、可撤销的同意。同意通过双重选择加入（double opt-in）机制获取。

## 五、数据安全措施 (Art. 32)

### 5.1 技术措施

| 措施 | 实现方式 |
|------|---------|
| 传输加密 | TLS 1.3（所有API和页面） |
| 存储加密 | AES-256（静态数据） |
| 数据库加密 | AWS RDS 加密（KMS 管理密钥） |
| 密钥管理 | AWS KMS，自动轮换 |
| 网络隔离 | VPC, Security Groups, NACLs |
| DDoS防护 | AWS Shield Standard |
| WAF | AWS WAF (OWASP Top 10) |
| 入侵检测 | AWS GuardDuty |
| 备份加密 | 备份数据同样加密存储 |

### 5.2 组织措施

- 最小权限原则：员工仅获得工作所需的最少数据访问权限
- 访问审批：数据库访问需经过审批流程
- 安全培训：全员年度安全意识培训
- 事件响应：Incident Response Plan (IRP)
- 隐私影响评估 (DPIA)：新功能上线前必须评估
- 数据保护官 (DPO)：已指定DPO监督合规

### 5.3 加密密钥管理

- 使用 AWS KMS 管理加密密钥
- 密钥自动轮换（CMK年度轮换）
- 无硬编码密钥，所有密钥通过环境变量或密钥管理服务注入
- 密钥访问日志留存

## 八、数据泄露响应 (Art. 33-34)

### 8.1 泄露分类

| 级别 | 定义 | 响应时限 |
|------|------|---------|
| P0 - 严重 | 大规模敏感数据泄露 | 24小时内报告DPA |
| P1 - 高 | 少量数据或非敏感数据泄露 | 72小时内报告DPA |
| P2 - 中 | 可能影响但已缓解 | 记录并改进 |

### 8.2 响应流程

```
1. 检测与评估 (0-4h)
   ↓
2. 遏制措施 (4-12h)
   ↓
3. 通知DPA (P0: 24h内 / P1: 72h内)
   ↓
4. 通知受影响用户 (如高风险, 72h内)
   ↓
5. 调查与修复 (持续)
   ↓
6. 事后报告 (30天内)
```

### 8.3 泄露通知内容 (Art. 33(3))

- 数据泄露性质描述
- 受影响数据类别和大约数量
- 数据主体可能后果
- 已采取和计划采取的补救措施
- DPO联系方式

## 九、隐私影响评估 (DPIA, Art. 35)

### 9.1 必须进行DPIA的场景

- 系统性大规模处理个人数据
- 新技术使用（如AI/ML）
- 画像处理
- 涉及儿童数据
- 跨境传输

### 9.2 eCan DPIA 检查清单

所有新功能上线前必须通过以下检查：
- [ ] 是否涉及个人数据收集？
- [ ] 数据收集是否最小化？
- [ ] 处理目的是否合法、透明？
- [ ] 法律依据是否明确？
- [ ] 数据保留期是否合理？
- [ ] 是否有充分的安仒措施？
- [ ] 是否涉及跨境传输？
- [ ] 数据主体权利是否得到保障？
- [ ] 是否有DPA与处理商签订？

## 十、Cookie 合规 (ePrivacy / GDPR)

### 10.1 Cookie 分类和使用

| Cookie类型 | 示例 | 目的 | 法律依据 |
|-----------|------|------|---------|
| 必要Cookie | Session, Auth | 服务运行必需 | 无需同意 |
| 功能Cookie | 语言偏好 | 改善体验 | 合法利益 |
| 分析Cookie | Analytics | 产品改进 | 同意 |
| 营销Cookie | Ads | 广告定向 | 同意 |

### 10.2 Cookie 同意机制

- 首次访问显示Cookie Banner
- 用户可选择接受/拒绝非必要Cookie
- 同意记录存储
- 同意可随时撤回
- 拒绝时不加载相应Cookie
