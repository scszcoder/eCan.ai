# eCan.cn 中国法律合规清单

本文档列出 eCan.cn 在中国大陆运营所需的法律合规要求，包括 ICP 备案、ICP 许可证、个人信息保护（PIPL）、网络安全法等相关要求。

---

## 一、ICP 备案与许可证

### 1.1 ICP 备案（必须）

根据《互联网信息服务管理办法》，在中华人民共和国境内提供非经营性互联网信息服务，必须进行 ICP 备案。

| 项目 | 要求 | 状态 | 备注 |
|------|------|------|------|
| 域名备案 | fastprecisiontech.com 需在工信部备案 | ✅ 已完成 | 粤ICP备2021146525号-1 |
| 备案号展示 | 网站底部展示备案号 | ☐ 待完成 | 链接至工信部查询系统 |
| 备案变更 | 任何信息变更需30日内更新 | ☐ 待完成 | |

**备案材料清单**：
- [x] 企业营业执照（彩色扫描件）
- [x] 法人身份证正反面（彩色扫描件）
- [x] 网站负责人身份证正反面
- [x] 域名证书
- [x] 信息安全管理协议（接入商提供）
- [x] 网站备案信息真实性核验单

**备案流程**：
1. 在接入服务商（阿里云/腾讯云/华为云）提交备案申请
2. 接入服务商初审（1-2工作日）
3. 通信管理局终审（7-20工作日）
4. 备案号获取

### 1.2 ICP 增值电信业务许可证（可能需要）

根据业务形态，可能需要申请不同类型的增值电信业务许可证：

| 许可证类型 | 适用范围 | 是否需要 | 说明 |
|-----------|---------|---------|------|
| ICP 许可证 | 有偿信息服务 | ☐ 待评估 | 如提供付费会员服务 |
| EDI 许可证 | 交易平台服务 | ☐ 待评估 | 如提供交易撮合服务 |
| SP 许可证 | 移动网信息服务 | ☐ 不需要 | 目前无短信/彩信服务 |

**注意事项**：
- 如公司外资占比超过50%，可能无法申请 ICP 许可证
- 外资限制具体规定见《外商投资电信企业管理规定》
- 建议咨询专业法律顾问评估是否需要

## 二、个人信息保护（PIPL）合规

### 2.1 个人信息收集合规

根据《个人信息保护法》，收集个人信息需遵循以下原则：

| 合规要求 | 实现方式 | 状态 |
|---------|---------|------|
| 告知同意 | 隐私政策明确告知收集目的、方式、范围 | ☐ 待完成 |
| 最小必要 | 仅收集实现目的所必需的最小数据集 | ☐ 待审核 |
| 单独同意 | 敏感个人信息需单独征得同意 | ☐ 待审核 |
| 撤回同意 | 用户可撤回同意，不影响已同意部分 | ☐ 待实现 |

**敏感个人信息识别**：

| 数据类型 | 是否收集 | 法律依据 |
|---------|---------|---------|
| 真实姓名 | ☐ | 实名认证场景单独同意 |
| 身份证号 | ☐ | 实名认证场景单独同意 |
| 手机号码 | ☐ | 服务必需，但需告知 |
| 生物识别信息 | ☐ | 明确禁止，除非特定场景 |
| 位置信息 | ☐ | 精确位置需单独同意 |
| 财产信息 | ☐ | 支付场景单独同意 |

### 2.2 数据本地化存储

根据《个人信息保护法》和《数据安全法》：

| 要求 | 说明 | 状态 |
|------|------|------|
| 境内存储 | 中国用户个人信息存储在中国境内服务器 | ☐ 已实现（腾讯云广州） |
| 出境评估 | 如需跨境传输需通过国家网信办评估 | ☐ 不适用 |
| 数据分类 | 建立数据分类分级制度 | ☐ 待建立 |
| 重要数据 | 如涉及重要数据需申报安全评估 | ☐ 待评估 |

### 2.3 个人信息主体权利

| 权利 | 实现方式 | 状态 |
|------|---------|------|
| 查阅权 | 用户可查看个人信息 | ☐ 待实现 |
| 更正权 | 用户可更正不准确的个人信息 | ☐ 待实现 |
| 删除权 | 账号注销后删除数据 | ☐ 待实现 |
| 撤回同意 | 可撤回授权同意 | ☐ 待实现 |
| 注销权 | 提供便捷的账号注销入口 | ☐ 待实现 |
| 副本权 | 可导出个人信息副本 | ☐ 待实现 |
| 投诉权 | 公开投诉渠道和联系方式 | ☐ 待完成 |

## 三、网络安全法合规

### 3.1 网络安全等级保护（等保）

根据《网络安全法》和《网络安全等级保护条例》，网络运营者需按照规定进行等级保护定级备案。

| 等保级别 | 适用场景 | 定级建议 | 状态 |
|---------|---------|---------|------|
| 一级 | 一般系统 | 可自评 | ☐ |
| 二级 | 重要系统 | 需测评 | ☐ 待评估 |
| 三级 | 关键信息基础设施 | 强制测评 | ☐ |

**eCan 建议定级为二级**，需完成：
- [ ] 系统定级备案
- [ ] 差距分析
- [ ] 安全建设和整改
- [ ] 等级测评
- [ ] 应急响应预案

### 3.2 日志留存

根据《网络安全法》和《互联网信息服务管理办法》：

| 数据类型 | 留存期限 | 法律依据 | 状态 |
|---------|---------|---------|------|
| 访问日志 | 不少于6个月 | 网安法第21条 | ☐ 待实现 |
| 操作日志 | 不少于6个月 | 网安法第21条 | ☐ 待实现 |
| 用户注册信息 | 不少于6个月 | 实名制要求 | ☐ 待实现 |
| 运行日志 | 不少于6个月 | 等保要求 | ☐ 待实现 |

### 3.3 安全技术措施

根据《网络安全法》和等保要求：

| 技术措施 | 要求 | 状态 |
|---------|------|------|
| 身份鉴别 | 用户身份标识和鉴别 | ☐ 待实现 |
| 访问控制 | 基于角色的访问控制 | ☐ 待实现 |
| 安全审计 | 记录用户行为和安全事件 | ☐ 待实现 |
| 入侵防范 | 检测和防止网络攻击 | ☐ 待实现 |
| 恶意代码防范 | 防病毒和恶意软件 | ☐ 待实现 |
| 数据备份 | 定期备份，关键数据加密 | ☐ 待实现 |

## 四、内容合规

### 4.1 AI 生成内容合规

eCan 作为 AI 辅助工具，需注意：

| 合规要求 | 实现方式 | 状态 |
|---------|---------|------|
| 内容审核 | 对用户输入和AI输出进行内容安全检测 | ☐ 待实现 |
| 违规处置 | 建立违规内容发现和处置机制 | ☐ 待建立 |
| 违法信息报告 | 发现违法信息及时向主管部门报告 | ☐ 待建立 |
| 保存记录 | 保存违法内容处置记录至少6个月 | ☐ 待实现 |

**内容安全检测方案**：
- 接入腾讯云内容安全 API 或阿里云内容安全
- 对用户输入和AI输出进行实时检测
- 涉黄、涉政、涉暴内容自动过滤
