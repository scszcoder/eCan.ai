# 应用商店审核提交流程

本文档说明 eCan.cn 和 eCan.ai 两个应用在各应用商店的审核提交流程。

---

## 一、CN 应用商店

### 1.1 华为 AppGallery

**前提条件**：
- 华为开发者账号（企业认证）
- ICP 备案
- 隐私政策 URL（HTTPS）
- 应用签名证书

**提交步骤**：

```
1. 准备材料
   ├── 应用安装包（.apk / .aab）
   ├── 应用截图（手机/平板各尺寸）
   ├── 应用图标（多种分辨率）
   ├── 隐私政策
   ├── 用户协议
   └── 功能描述文档

2. 创建应用
   ├── 登录 AppGallery Connect
   ├── 进入"我的应用" → "新建应用"
   ├── 选择平台：Android
   ├── 填写基本信息（应用名称、包名）
   └── 上传应用

3. 配置应用信息
   ├── 填写应用分类
   ├── 上传应用截图和图标
   ├── 填写应用描述
   └── 设置年龄分级

4. 提交审核
   ├── 选择分发国家和区域
   ├── 设置定价（免费/付费）
   └── 提交审核

5. 审核周期
   └── 通常3-7个工作日
```

**常见被拒原因及解决方案**：

| 被拒原因 | 解决方案 |
|---------|---------|
| 隐私政策链接无效 | 确保 HTTPS 可访问，页面包含应用名称 |
| 缺少用户协议 | 提供完整的服务条款页面 |
| 功能描述不清晰 | 提供详细的功能说明文档 |
| 权限申请说明不足 | 在隐私政策中明确说明每个权限用途 |
| 应用闪退/无法运行 | 使用华为真机测试，确保兼容性 |

### 1.2 小米应用商店

**前提条件**：
- 小米开发者账号（企业认证）
- 应用签名

**提交步骤**：

```
1. 登录小米开放平台 (https://dev.mi.com)
2. 进入"应用市场" → "应用上传"
3. 填写应用基本信息
4. 上传安装包
5. 填写应用详情
6. 提交审核（审核周期：3-5个工作日）
```

### 1.3 OPPO 软件商店

**前提条件**：
- OPPO 开发者账号（企业认证）

**提交步骤**：

```
1. 登录 OPPO 开放平台 (https://open.oppomobile.com)
2. 进入"应用上传"
3. 填写应用信息
4. 上传应用包
5. 提交审核（审核周期：2-5个工作日）
```

### 1.4 vivo 应用商店

**前提条件**：
- vivo 开发者账号（企业认证）

**提交步骤**：

```
1. 登录 vivo 开放平台 (https://dev.vivo.com.cn)
2. 进入"应用管理" → "上传应用"
3. 填写应用信息
4. 上传安装包
5. 提交审核（审核周期：3-7个工作日）
```

## 二、Intl 应用商店

### 2.1 Apple App Store

**前提条件**：
- Apple Developer Program 账号（$99/年，企业账号）
- Mac 电脑（用于 Xcode 上传）
- 签名证书和 Provisioning Profile

**提交步骤**：

```
1. 准备材料
   ├── 应用安装包（.ipa via Xcode）
   ├── App Store 截图
   │   ├── 6.7" iPhone（1290 x 2796）
   │   ├── 6.5" iPhone（1284 x 2778）
   │   ├── 5.5" iPhone（1242 x 2208）
   │   ├── iPad Pro 12.9"（2048 x 2732）
   │   └── iPad Pro 11"（1668 x 2388）
   ├── 应用图标（1024 x 1024）
   ├── 隐私政策 URL
   └── 营销联系人信息

2. 创建 App Store Connect 应用
   ├── 登录 App Store Connect
   ├── 进入"我的 App" → "+"
   ├── 选择平台：iOS
   ├── 填写基本信息
   └── 选择 Bundle ID

3. 配置 App 信息
   ├── 填写名称、副标题
   ├── 上传截图
   ├── 填写描述、关键词
   ├── 设置价格和分发范围
   ├── 填写隐私政策 URL
   └── 配置内容分级

4. Xcode 构建和上传
   ├── 配置签名（Automatic Signing）
   ├── Archive 项目
   ├── Distribute to App Store
   └── 等待构建版本出现在 App Store Connect

5. 提交审核
   ├── 在 App Store Connect 选择构建版本
   ├── 填写审核账号信息（如需要测试账号）
   ├── 添加审核备注（可选）
   └── 点击提交审核

6. 审核周期
   └── 通常24-48小时，快速通道可选
```

**App Store 审核指南检查清单**：

- [ ] 无崩溃或重大Bug
- [ ] 所有链接可正常访问（隐私政策、服务条款）
- [ ] 应用描述与实际功能一致
- [ ] 无误导性内容
- [ ] 符合年龄分级
- [ ] 无侵权内容
- [ ] 隐私政策符合 GDPR/App Privacy 要求

**App Privacy 披露**：

Apple 要求在 App Store Connect 中披露所有数据收集：

| 数据类型 | 收集 | 用途 | 追踪 |
|---------|------|------|------|
| 联系方式 | 是 | 账号注册 | 否 |
| 标识符 | 是 | 账号、推送 | 否 |
| 使用数据 | 是 | 产品改进 | 可选 |
| 诊断数据 | 是 | Bug追踪 | 否 |
| 付款信息 | 是 | 支付处理 | 否 |

### 2.2 Google Play Store

**前提条件**：
- Google Play 开发者账号（$25一次性，企业账号）
- Google Sign-in OAuth 客户端（可选）

**提交步骤**：

```
1. 准备材料
   ├── 应用安装包（AAB 格式，via Android Studio）
   ├── Play Store 截图
   │   ├── 手机截图（至少2张）
   │   └── 平板截图（可选）
   ├── 应用图标（512 x 512 PNG）
   ├── Feature Graphic（1024 x 500 PNG）
   ├── 隐私政策 URL
   └── 数据安全表单填写

2. 创建 Google Play Console 应用
   ├── 登录 Google Play Console
   ├── 进入"所有应用" → "创建应用"
   ├── 选择默认语言，填写应用名称
   └── 选择应用类型：工具类

3. 配置应用信息
   ├── 填写商品详情（名称、描述、截图）
   ├── 设置分类和标签
   ├── 填写联系方式
   ├── 上传 AAB 安装包
   └── 填写内容分级问卷

4. 数据安全表单（重要！）
   必须在 Play Console 中填写数据安全表单：
   ├── 声明收集的数据类型
   ├── 声明数据用途
   ├── 声明是否用于追踪
   ├── 提供隐私政策链接
   └── 声明是否加密传输

5. 定价和分发
   ├── 设置价格（免费/付费）
   ├── 选择分发国家/地区
   └── 配置设备兼容性

6. 提交审核
   └── 点击"发布"（审核周期：2-7天）

7. 常见被拒原因
   ├── 崩溃或ANR
   ├── 诱导评分
   ├── 权限申请不合理
   ├── 广告不符合规范
   └── 数据安全表单填写不完整
```

### 2.3 Microsoft Store（Windows）

**前提条件**：
- Microsoft 合作伙伴中心账号（企业）
- 代码签名证书

**提交步骤**：

```
1. 准备材料
   ├── MSIX 安装包
   ├── Store 截图
   ├── 应用图标（50x50, 150x150, 宽图标)
   └── 隐私政策 URL

2. 创建应用
   ├── 登录合作伙伴中心
   ├── 进入"应用和服务" → "创建新应用"
   ├── 保留应用名称
   └── 填写产品 ID

3. 配置应用
   ├── 上传 MSIX 包
   ├── 填写描述和截图
   ├── 设置年龄分级
   ├── 填写隐私政策
   └── 配置分销国家

4. 提交审核
   └── 点击提交（审核周期：1-3天）
```

## 三、提交前检查清单

### 3.1 通用检查

| 检查项 | CN | Intl |
|--------|-----|------|
| 隐私政策页面可访问（HTTPS） | ☐ | ☐ |
| 服务条款页面可访问（HTTPS） | ☐ | ☐ |
| 应用图标准备完毕 | ☐ | ☐ |
| 应用截图准备完毕 | ☐ | ☐ |
| 应用签名正确 | ☐ | ☐ |
| 版本号符合规范 | ☐ | ☐ |
| 隐私政策包含商店名称 | ☐ | ☐ |
| ICP备案号准备好（如需） | ☐ | N/A |

### 3.2 CN 应用检查

| 检查项 | 说明 |
|--------|------|
| ICP备案号 | 网站底部展示 |
| 隐私政策 | 包含微信/Alipay SDK说明 |
| 实名认证 | 付费功能需实名 |
| 未成年人保护 | 建议提供说明 |

### 3.3 Intl 应用检查

| 检查项 | 说明 |
|--------|------|
| App Privacy 披露 | App Store Connect 填写 |
| 数据安全表单 | Google Play 填写 |
| 第三方 SDK 隐私政策 | 需提供链接 |
| GDPR 合规 | 欧盟用户权利保障 |
