# Tencent Backend Source

The Tencent CloudBase GraphQL SCF and WebSocket service implementation is
maintained in the private `eCan_lambda` repository under
`cn/tencent/cloudbase-graphql/`.

This public repository contains client integrations, endpoint configuration, and
high-level architecture documentation only. Do not add Tencent cloud-function
source, deployment secrets, generated deployment artifacts, or private backend
configuration to this repository.
